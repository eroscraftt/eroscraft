EROSCRAFT — WEB SİTESİ

1. index.html dosyasını tarayıcıda açarak siteyi inceleyebilirsiniz.
2. Siteyi GitHub Pages, Netlify veya benzeri statik barındırmaya yükleyebilirsiniz.
3. Siparişleri WhatsApp'a yönlendirmek için index.html içindeki:
   const WHATSAPP_NUMBER = '';
   satırına numaranızı 90 ile başlayan, + ve boşluk içermeyen biçimde yazın.
4. Numara tanımlanana kadar müşteri sipariş mesajını kopyalayabilir; site siparişi otomatik kaydetmez veya işletmeye iletmez.
5. Bu sürüm ödeme, stok, yönetici paneli, dosya yükleme, sipariş veritabanı veya otomatik e-posta içermez.
6. Fiyatlar teklif usulüdür. Görseller konsept amaçlıdır; gerçek ürün fotoğraflarıyla değiştirin.
7. Müşteriden iletişim bilgisi istendiği için yayına almadan önce KVKK aydınlatma metni ve satış/mesafeli satış yükümlülüklerini değerlendirin.
